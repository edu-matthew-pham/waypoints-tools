1 Collect examples

Make one group (class) for each thing you want to tell apart. Give each group at least 20 examples from different angles, distances and lighting.

Save project puts your classes and examples in a file, so you can carry on next lesson. It doesn't save the trained model: just train again.

The model only sees what's inside this square. It's shown like a mirror, but saved the right way round.

Good habits: train on things, not people, where you can: objects, drawings, hand signs. If your project needs faces, use only your own, and never other people's without asking. Check what's behind you before you record.

2 Train

Test settings (shown because the address ends in ?settings=1).

How well does it do on new examples?

How this works: before the final training, the trainer held back the newest 20% of each class's examples, trained without them, then tested on them. If you recorded each class in one go, those examples look a lot like the rest, so it will do worse in real life. Test with new photos and different backgrounds too.
